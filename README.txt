大戦機 3D ビューア (P-51D / Me 262 / グロスター ミーティア + 空軍基地)

index.html をブラウザで開くだけで動きます(オフライン可・three.js r147 は lib/ に同梱)。
src/ は元のソースです(assemble.py → build.py で index.html 相当を再生成。パスは作業環境のものなので適宜修正してください)。

【搭乗】背景を「空軍基地」にすると、パネルに「搭乗」ボタンが出ます。押すと滑走路から実際に離陸・飛行できます(操作はパネルの説明、スマホはスティック/スロットル表示)。実装は src/fly.js です。

【飛行モデル】旋回時間・上昇率・離陸滑走距離を War Thunder (RB・改造済み)の公表値に較正しています(P-51D-30 / Me 262 A-1a / Meteor F Mk 3)。パラメータは src/fly.js 冒頭の FLYP にあります。海面最高速は公表値がないため推定です。

【新マップ(広域拡張)】2026-10 更新
既存の空軍基地を中心に、周辺の広域マップ(約 3.4 km × 2.4 km)を追加しました。
  - 地表テクスチャ: 畑(区画ごとに色と畝の向きが違う)・草地・道路・2本の川(src/map/region.jpg)
  - 森林: 線画の樹木記号の密度から森林域を抽出し、立体の木を約5万本インスタンス描画(針葉樹/広葉樹)
  - 集落: 地図上の家屋記号を立体化(約70棟)、点在する木も配置
  - 橋: 川と道路の交差点7か所に橋桁を配置
  - 基地の高精細テクスチャ(ground.jpg)は柵の外側だけを新マップに置き換えて継ぎ目なく合成
  - 滑走路の進入路の延長線上は木を置かず、離着陸の邪魔にならないようにしています
  - カメラに「広域」ボタンを追加。描画距離とズームアウト上限も広域に合わせて拡大
  - <meta charset="utf-8"> を追加(サーバ経由で開いても文字化けしないように)
変更したコード: src/airbase.js(region / forests / houses / bridges の追加)、src/assemble.py・src/template.html・src/build.py(新データの埋め込み)
