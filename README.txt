大戦機 3D ビューア (P-51D / Me 262 / グロスター ミーティア + 空軍基地)

index.html をブラウザで開くだけで動きます(オフライン可・three.js r147 は lib/ に同梱)。
src/ は元のソースです(assemble.py → build.py で index.html 相当を再生成。パスは作業環境のものなので適宜修正してください)。

【搭乗】背景を「空軍基地」にすると、パネルに「搭乗」ボタンが出ます。押すと滑走路から実際に離陸・飛行できます(操作はパネルの説明、スマホはスティック/スロットル表示)。実装は src/fly.js です。

【飛行モデル】旋回時間・上昇率・離陸滑走距離を War Thunder (RB・改造済み)の公表値に較正しています(P-51D-30 / Me 262 A-1a / Meteor F Mk 3)。パラメータは src/fly.js 冒頭の FLYP にあります。海面最高速は公表値がないため推定です。
